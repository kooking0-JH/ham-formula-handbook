# 아마추어 무선 & 전파공학 공식 핸드북 (ham-formula-handbook)

아마추어 무선에서 자주 쓰는 공식 24개와 저항 색띠 코드표를 한 페이지에 모은 편람입니다. 공식마다 수식, 기호와 단위, 의미와 운용 포인트를 함께 적었습니다.

## 구성

1. 직류와 기초 전기 회로 (01–04) — 옴의 법칙·도선 저항, 전력·효율, 저항 결합·전압 분배, 배터리 내부 저항
2. 교류, 수동 소자와 정류 회로 (05–08) — 실효값·정류, 커패시터, 인덕터, 변압기 권수비·트랜지스터·PLL
3. 고주파 회로, 공진과 주파수 변환 (09–12) — 리액턴스·임피던스, LC 공진·FM 대역폭, Q, 영상 주파수
4. 안테나, 급전선, 감쇠기와 ARDF 지향성 (13–18) — 다이폴·야기 절단식, SWR(빠른 참고표), 동축 손실, 1/4파장 정합, 루프·카디오이드(그림), T/π 감쇠기
5. 신호 세기, 데시벨과 전계 강도 (19–20) — dB·dBm·S-미터(암산표), dBd/dBi·ERP/EIRP·전계 강도
6. 전파 전파와 수신기 성능 (21–24) — FSPL·링크 버짓, 가시거리·프레넬, MUF, 열잡음·Friis·IIP3
- 부록: 저항 색띠 코드표 (4색띠·5색띠, IEC 60062)

맨 위의 목차 버튼을 누르면 그 장으로 이동하고, 「공식 찾기」 칸에 SWR·감쇠기·MUF 같은 말을 넣으면 해당 공식만 남습니다. 수식은 MathJax로 표시합니다.

## 게시

주소: https://kooking0-jh.github.io/ham-formula-handbook/

1. GitHub에서 새 저장소 `ham-formula-handbook` 생성 (Public)
2. `index.html`, `README.md`, `tistory-embed.html` 업로드
3. Settings → Pages → Branch: `main` / `(root)` → Save
4. 1~2분 뒤 주소 접속 확인

티스토리에는 `tistory-embed.html`의 코드를 글의 HTML 모드에 붙여 넣습니다(높이 자동 맞춤, 목차 링크 이동). 블로그(iframe) 삽입 규약은 antenna-types 규약을 그대로 씁니다.

## 확인한 환경

- 화면 폭 1280 / 375 / 320 px에서 페이지 가로 넘침 없음, 콘솔 오류 없음 (320 px에서는 긴 수식 1개와 표 1개만 그 칸 안에서 옆으로 밀어 봄)
- iframe 삽입 시 높이 자동 맞춤, 목차 링크 이동 확인
- 예시 수치(SWR별 반사 전력·리턴 로스·부정합 손실, 6 dB 감쇠기 저항값, 영상 주파수, 야기 소자 길이, dBm 환산, 잡음 바닥 차이)를 계산으로 다시 확인
